## Level 1 SBOM Invariant Verification (Stand: 2026-09-29)

All 10 architectural and runtime governance invariants are confirmed:
- INV-LOCAL-01: Local-First & Explicit Egress (Dashboard binds strictly to loopback 127.0.0.1; no background telemetry or phone-home requests; explicit gateway calls require configured HTTPS backends)
- INV-GATE-02: Fail-Closed Gateway Policy Guard (Gateway tool invocation gated strictly by data/gateway-policy.json; missing or invalid policy files refuse every call)
- INV-SUB-03: Ephemeral Child Process Boundaries (Connect-per-call stdio lifecycle; child processes terminate immediately after tool result delivery; zero zombie processes)
- INV-SCRUB-04: Bounded Result Redaction & Finite Budgets (Recursive secret scrubbing across payloads; key wiping confined to structured metadata; 256 KiB request & 1 MiB response budgets)
- INV-PRIV-05: Non-Elevation / RunAsInvoker (Operates strictly within unprivileged standard OS user space without administrative or root elevation)
- INV-LOCK-06: Canonical Multi-Agent Lock Awareness (Respects canonical multi-agent project locks LOCK*.txt, LOCK.user.*, LOCK.until.* fail-closed)
- INV-PERM-07: Nearest Permission Register Introspection (Recursively discovers and evaluates LOCK.permissions.json up directory trees)
- INV-GOV-08: Read-Only Host Governance Federation (Read-only federation of pending decisions, policy registry, strategic plans, and resource inventory)
- INV-SYNC-09: Cloud-Sync Conflict Hardening (.gitignore hardened against multi-host conflict copies, temporary files, and lock files)
- INV-SLA-10: 48h Security SLA & Coordinated Disclosure (Binding 48-hour response confirmation and 5-day triage commitment via canonical security channels)

Refer to `THIRD_PARTY_LICENSES.md` for full cross-reference matrix and component analyses.
