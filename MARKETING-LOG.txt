[POSITIONING & VALUE PROPOSITION]
ellmos ControlCenter MCP is the authoritative local control plane and policy-gated gateway
for Model Context Protocol (MCP) environments. It bridges multi-agent systems (Claude Code,
Codex, Gemini, Antigravity) with local tool catalogs, dynamic capability bundles, profile
switching, system governance mirrors (locks, permissions, decisions), and an on-demand
tool invocation gateway for unloaded backend MCP servers.

Key Differentiators:
1. Dual-Role Architecture: Seamlessly combines administrative control-plane inspection with
   a runtime policy-gated gateway that invokes tools on unloaded backend servers.
2. 100% Local-First & Zero-Egress: All discovery, profile resolution, and gateway forwarding
   run strictly on localhost (127.0.0.1); zero telemetry, zero cloud dependencies.
3. Fail-Closed Security & Eigendark Safety: Hardened against prompt injection with untrusted
   data wrapping, recursive credential scrubbing, finite memory/depth budgets, and connect-
   per-call process lifecycle management (zero zombie processes).
4. Host Governance Mirroring: Integrates canonical multi-agent project locks (LOCK*.txt),
   hierarchical permissions (LOCK.permissions.json), and user decisions.

[TARGET PERSONAS]
1. AI Infrastructure Engineers & Tooling Architects:
   - Need to manage growing fleets of MCP servers without overloading agent context windows.
   - Seek reproducible profile configurations, inheritance chains, and capability bundling.
2. Multi-Agent System Operators (Claude Code, Codex, Antigravity):
   - Require dynamic on-demand tool access (`controlcenter_invoke`) without pre-loading dozens
     of heavy MCP servers into active token windows.
3. Security-Conscious Teams & Enterprise Developers:
   - Demand strict zero-egress guarantees, fail-closed policy gates, recursive secret redaction,
     and structured audit trails (`gateway-audit.jsonl`).
4. Solo Hackers & Open-Source Maintainers:
   - Need instant visibility into installed skills, local repositories, and active locks via
     an intuitive local dashboard (`127.0.0.1:3737`).
